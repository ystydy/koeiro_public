プライバシーポリシー

最終更新日：2026年03月19日

本プライバシーポリシー（以下「本ポリシー」）は、開発者（以下「開発者」）が提供するモバイルアプリケーション「LiarDoku 嘘独」（以下「本アプリ」）において、ユーザーの情報をどのように取得・利用・管理するかを定めるものです。本アプリをご利用いただく前に必ずお読みください。

1. 取得する情報

1-1. ユーザーが提供する情報

情報の種類内容
ニックネームユーザーが任意で設定した表示名（2〜10文字）。ランキング表示に使用します。

1-2. アプリが自動的に取得する情報

情報の種類内容
ユーザー識別子（UID）Firebase 匿名認証により自動生成される匿名ID。個人を特定する情報は含みません。
ゲームプレイデータクリアステージ数・タイムアタック記録・デイリーチャレンジの達成状況・連続プレイ日数（ストリーク）・獲得称号
スコアデータタイムアタックモードのスコア・プレイ時間・ミス回数。グローバルランキングに登録する場合に使用します。
端末情報OS種別・バージョン、アプリバージョン、言語設定
広告識別子IDFA（iOS）・GAID（Android）等、広告配信SDKが収集する広告識別子
利用ログアプリの操作ログ・クラッシュログ・パフォーマンス情報（Firebase Analytics / Crashlytics / Performance Monitoring）

2. 利用目的

取得した情報は以下の目的にのみ使用します。

利用目的対象データ
ゲームの進行管理・セーブデータの同期UID、ゲームプレイデータ
グローバルランキングへの掲載UID、ニックネーム、スコアデータ
デイリーチャレンジ・プッシュ通知の配信UID、ゲームプレイデータ（ストリーク数）
広告の配信・最適化広告識別子、端末情報
アプリの改善・バグ修正クラッシュログ、利用ログ、パフォーマンス情報
Firebase Analytics によるアプリ利用状況の分析利用ログ、端末情報

3. 第三者提供・利用するサービス

本アプリは以下の第三者サービスを利用します。各サービスのプライバシーポリシーも合わせてご確認ください。

3-1. Firebase（Google LLC）

ゲームデータの保存・認証・分析・クラッシュレポート・パフォーマンス計測に Firebase を使用します。

  • Firebase Authentication（匿名認証）
  • Cloud Firestore（ゲームデータ保存）
  • Firebase Analytics（利用状況分析）
  • Firebase Crashlytics（クラッシュレポート）
  • Firebase Performance Monitoring（パフォーマンス計測）
  • Firebase Remote Config（機能フラグ管理）
  • Firebase Cloud Messaging（プッシュ通知）

Google のプライバシーポリシー

3-2. Google AdMob（Google LLC）

広告表示のために Google AdMob を使用します。AdMob は端末情報・広告識別子を収集し、パーソナライズ広告の配信に利用する場合があります。

Google のプライバシーポリシー

3-3. 法的要請

法令に基づく適法な開示要求がある場合、必要最小限の範囲で情報を提供することがあります。

本アプリは匿名認証を使用しているため、氏名・メールアドレス・電話番号などの個人を直接特定できる情報は取得しません。

4. データの保存期間・削除

データ種別保存場所削除方法
ゲームプレイデータ・スコアCloud Firestore（クラウド）お問い合わせよりデータ削除を申請できます
ローカルキャッシュ（ニックネーム等）端末内（SharedPreferences）アプリのアンインストールで削除
クラッシュログ・分析データFirebase（クラウド）Firebase のデータ保持ポリシーに準じます

5. プッシュ通知

本アプリはデイリーチャレンジのリマインダーとしてプッシュ通知を送信します。通知は端末の設定からいつでもオフにできます。

  • iOS：「設定」→「通知」→「LiarDoku」→「通知を許可」をオフ
  • Android：「設定」→「アプリ」→「LiarDoku」→「通知」をオフ

6. ユーザーの権利

  • データの確認・削除：ゲームデータの削除を希望される場合は、下記連絡先よりお申し付けください。
  • 広告のパーソナライズ設定：iOS設定の「プライバシーとセキュリティ」→「トラッキング」から広告識別子の利用を制限できます。Android はGoogle設定から広告IDをリセット・削除できます。
  • 同意の撤回：本アプリの利用を停止しアンインストールすることで、データ収集への同意を撤回できます。
  • お問い合わせ：下記連絡先よりご連絡ください。

7. セキュリティ

本アプリは Firebase の認証・暗号化通信（HTTPS）を使用してデータを保護しています。ただし、インターネット経由の通信においてリスクをゼロにすることはできません。不審な点にお気づきの場合は、下記連絡先までお知らせください。

8. 子どものプライバシー

本アプリは13歳未満の方を対象としておりません。13歳未満の方が本アプリをご利用になる場合は、保護者の同意のもとでご利用ください。

9. 改定

本ポリシーは、法令の改正・機能追加・方針変更に伴い改定する場合があります。重要な変更がある場合は、アプリ内またはApp Store / Google Playのアップデート説明にてお知らせします。
